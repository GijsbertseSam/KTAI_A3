# KTAI_A3
KTAI Assignment 3 - Using PPO in a SimGlucose environment: an exploratory study

Requirements.txt provides the versions of the dependencies in the Jupyter notebook.
RL_SimGlucose.ipynb provides the code to recreate the models and results.

Use the switch load_existing_models = True/False in chapter "PPO Training or Loading" to either load the provided models or re-create the models.
